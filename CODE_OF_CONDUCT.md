# Code of Conduct

We want Mia Code to be a welcoming project for everyone, regardless of experience, background or identity.

**Expected:** be respectful and constructive; assume good faith; give and accept feedback graciously; focus on the work; credit others.

**Not acceptable:** harassment, discrimination, personal attacks, insults, doxxing or publishing others' private information, sexualised language or
attention, and sustained disruption of discussions.

**Scope:** project spaces (repository, issues, pull requests, discussions) and public representation of the project.

**Enforcement:** maintainers may edit or remove contributions and restrict participation that violate this code. Report concerns to the maintainers
(contact address to be set by the maintainers before the first public release; until then, use a private message to a maintainer on GitHub).

This is a short project-specific code; maintainers may replace it with an established standard such as the Contributor Covenant.
